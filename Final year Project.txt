============================================================================================================================================================================================


PULSE PLATE is an AI-powered smart transport management system designed for educational institutions. The system automatically identifies college buses using Automatic Number Plate Recognition (ANPR), maintains digital attendance of bus entry and exit, verifies driver identity, monitors driver safety, and provides live transport information to administrators, drivers, and students.

The solution consists of an edge device installed at the campus gate and two software interfaces (Administrative Portal and Student Portal) connected through a centralized SQL database.

The deployment location is Coimbatore, Tamil Nadu.

2. Hardware System

The edge device consists of:

Raspberry Pi / Edge Controller
HD Camera
Power Supply Unit
Internet Connectivity (Wi-Fi/Ethernet)
Optional UPS

The device captures every incoming and outgoing bus and transmits the information to the server.

3. AI Features
Number Plate Recognition
Detect bus number plate
Match with registered bus
Record entry and exit time
Driver Verification
Detect driver's face
Compare with registered driver
Report mismatch
Driver Monitoring
Detect drowsiness
Detect seat belt usage
Generate safety alerts
